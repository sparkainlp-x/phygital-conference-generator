# Changelog — Holographic Phygital Conference Plan Generator

## 0.1.0 (2026-11-21)

First release. The generator takes a country profile and writes the full
WorldHoloBridge conference plan for that country: six phases, five
holographic tiers, both worked examples (Hall of Memory museum, Cadre
artistique publicity), the twelve-rule governance checklist, the adopted
demo tiers, and the 90-day Country Node pilot. Built-in profiles: Canada,
Morocco, Germany, France, United Kingdom. A new country is a copied JSON
file, no code change. Standard library only.

- 19 tests, all passing: every generated plan is checked for all six
  phases, all five tiers, both examples, the full governance checklist,
  and the demo tiers at the adopted prices.
- Companion plan document in `docs/holographic-phygital-society-plan.md`
  (14-page PDF in the delivery folder).
- Example generated plans for Morocco and Canada in `examples/`.
- All ideas are sparkainlp-x's own. The one external name in the first
  draft (a theory author's metaphysics, named in a disclaimer) was
  removed before this release; the guardrail stays, the name is gone.
  Third-party products (Looking Glass, Sony ELF-MN1) and the Marie Curie
  example figure are named as products and examples, not claimed as
  ideas.
